# Portfolio Website

M. Berkay Önen's personal portfolio site — a showcase of selected projects, built with Next.js and Tailwind CSS.

## Tech stack

- **Next.js 14** (App Router)
- **Tailwind CSS** for styling, with the typography plugin
- **Vitest** + Testing Library for component tests

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it.

## Testing

```bash
npm test
```

## Deployment

Deployed on [Vercel](https://vercel.com).
